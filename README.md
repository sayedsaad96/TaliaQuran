# Talia

> A Local-First Quran Platform for Reading, Memorization, Review, and Long-Term Progress.

---

# Vision

Talia helps Muslims build a lifelong relationship with the Quran.

The application combines:

- Quran Reading
- Memorization
- Smart Review
- Smart Coach
- Progress Tracking
- Kids Experience
- Parent Mode

while remaining fully functional offline.

# Product Philosophy

Reading and memorization are two different user experiences built on the same Quran data.

The Quran is the center of the application.

Everything else exists to support the user's journey.
